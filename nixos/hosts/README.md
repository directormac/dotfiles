## Installing to a new host

Create a bootable ISO USB Stick using

Use `lsblk -S` to display devices this will show you vendor model and `TRAN` which should say USB
or pipe it to `grep like this`

```sh
lsblk -o NAME,SIZE,VENDOR,MODEL,SERIAL,TRAN | grep "TRAN|usb"
```

Then replace the `sdX` with the NAME e.g `sdz` in our `dd` command

```sh
dd bs=4M if=/path/to/latest-nixos-minimal-x86_64-linux.iso \
  of=/dev/sdX cov=fsynv oflag=direct status=progress
```

Boot into a minimal [ISO](https://nixos.org/download/#nixos-iso)

You are `Groot!` run `sudo su` immediately!!

clone the repository

```sh
nix-shell -p git --run "git clone https://github.com/directormac/dotfiles.git"
cd dotfiles
```

Find your desired disk to start the `panic @t disko!`

Optional preparation for disco depending on how [complex](https://github.com/nix-community/disko/blob/master/example/complex.nix) your configuration is generate a `_hardware.nix`

```sh
nixos-generate-config --no-filesystems --show-hardware-config > install/_hardware.nix
```

Which should look like this.

```nix
# Do not modify this file!  It was generated by ‘nixos-generate-config’
# and may be overwritten by future invocations.  Please make changes
# to /etc/nixos/configuration.nix instead.
{
  config,
  lib,
  pkgs,
  modulesPath,
  ...
}: {
  imports = [
    (modulesPath + "/profiles/qemu-guest.nix")
  ];

  boot.initrd.availableKernelModules = ["ahci" "virtio_pci" "xhci_pci" "sr_mod" "virtio_blk"];
  boot.initrd.kernelModules = [];
  boot.kernelModules = ["kvm-intel"];
  boot.extraModulePackages = [];

  nixpkgs.hostPlatform = lib.mkDefault "x86_64-linux";
}
```

If you are not doing anything fancy a `disco.nix` that is like this will work anywhere.
a minimal `disco.nix` in hosts/minimal

```nix
{
  disko.devices = {
    disk = {
      main = {
        device = "/dev/vda";
        type = "disk";
        content = {
          type = "gpt";
          partitions = {
            boot = {
              size = "1M";
              type = "EF02"; # for grub MBR
            };
            ESP = {
              name = "ESP";
              size = "1G";
              type = "EF00";
              content = {
                type = "filesystem";
                format = "vfat";
                mountpoint = "/boot";
                mountOptions = ["umask=0077"];
              };
            };
            root = {
              name = "root";
              size = "100%";
              content = {
                type = "filesystem";
                format = "ext4";
                mountpoint = "/";
              };
            };
          };
        };
      };
    };
  };
}
```

explore mountpoints

```sh
mount | grep /mnt
# Look for mount points and desired partitions.

# Inspect the create partiions, their labels and flags.
gparted

# Explore the created LVM volumes.

# Physical Volumes.
pvs

vgs
# Logical Volumes.
lvs
```

Copy dots to

```sh
cp -r . /mnt/etc/nixos
```

Install !!!

```sh
 nixos-install --flake /mnt/etc/nixos#<hostName>
```

## Troubleshooting

### Delete a broken build

Run the commands on the working one

```sh
# List generations
sudo nix-env --list-generations --profile /nix/var/nix/profiles/system
# Remove the target ID e.g 42
sudo nix-env --delete-generations ID --profile /nix/var/nix/profiles/system

# Clean up to update the boot menu
sudo nix-collect-garbage -d
sudo nixos-rebuild switch --flake .#hostname
```
